# MediaStrike layout correspondence to the creator reference

Reference: [Juxtopposed's VLC redesign video](https://www.youtube.com/watch?v=ERFeOgqk324), inspected at the times below on 15 October 2026. The video description links the [Figma community file](https://www.figma.com/community/file/1691465999134370980). The Figma page identified the file and creator, but its canvas and reuse terms were unavailable, so MediaStrike uses no copied VLC or Figma graphics.

| Video point | Visible reference layout | Current MediaStrike | Remaining difference |
| --- | --- | --- | --- |
| Around 09:30, player with playlist | Thin title bar, almost-black video canvas, orange emphasis in a compact transport strip along the bottom, and a playlist panel at the right | The earlier captured player has a near-black canvas, orange playback/selection emphasis, bottom transport, and a right session queue; this draft removes the permanent title-bar publisher mark | The text navigation rail remains visible; the reference player gives more width to video. The queue lacks the reference's per-item durations and compact row controls. |
| Around 13:30, media browsing | Narrow icon rail on the far left and a file list to the left of the preview, with breadcrumb, count, search, and sort controls | Text navigation rail on the left; a searchable queue on the right, and a proposed chosen-folder file list beside the preview | The proposed folder browser lists supported regular files from one chosen directory, with search, count, and name-order toggle; native rendering remains unverified. It is not a recursive library and has no breadcrumb navigation, thumbnails, duration, or file metadata. |
| Around 14:30, video-focused player | Playlist hidden, video takes nearly the full window, and one slim transport row remains at the bottom | [New focus-view capture](../assets/screenshots/mediastrike-focus-1517f4a.png) shows the video across the window with both rails hidden and one compact transport row. F11, a button, or `--focus-view` selects it | The captured view is windowed; actual display fullscreen and native F11/button clicks remain unverified. |
| Around 15:30, command menu | Menu shows Convert, Stream, Open Recent, Customize Player, Plugins & Extensions, Settings, and About | About is available; local open and queue controls are visible elsewhere | The listed commands and settings are not implemented. They are tracked in `VLC_PARITY.md`, not represented as working UI. |

These are observations from the video's rendered interface, not a pixel specification. The reviewed queue and focus screenshots are MediaStrike's own native captures with synthetic media, not images from the video. The original PWDS and lyrebird branding stays in the app.

The proposed folder browser and title-bar change in draft PR #10 are source changes only. The linked normal/focus screenshots predate them; the hosted Windows GUI lacks a usable OpenGL 2.0 context for a fresh capture.
